# RI-fruits-vegetables
Classification using neural networks

This project presents a Python-based solution aimed at utilizing neural networks to recognize and categorize different types of fruits and vegetables. By using deep learning algorithms, our work seeks to automate the classification process, thereby simplifying tasks that have traditionally relied on human judgment.

Fruits and vegetables dataset: https://www.kaggle.com/datasets/kritikseth/fruit-and-vegetable-image-recognition

Ovaj rad predstavlja Python projekat koji ima za cilj da iskoristi neuronske mreže kako bi prepoznao i kategorizovao različite vrste voća i povrća. Korišćenjem algoritama dubokog učenja, naš projekat ima za cilj da automatizuje proces klasifikacije, čime se olakšavaju zadaci koji su do sada zavisili od ljudske procene.

Skup podataka voća i povrća:: https://www.kaggle.com/datasets/kritikseth/fruit-and-vegetable-image-recognition
